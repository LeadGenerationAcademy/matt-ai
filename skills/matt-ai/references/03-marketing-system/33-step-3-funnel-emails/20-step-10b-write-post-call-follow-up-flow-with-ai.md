### AI Prompt:

Using only the AI Company Context Document below, write the complete Follow-Up Flow.

This flow is for prospects who completed a sales call but did not buy.

Use this schedule:

- Day 1: Biggest case study
- Day 2: Biggest percentage transformation
- Day 3: Best tip
- Day 5: FAQ #1
- Day 7: FAQ #2
- Day 9: FAQ #3
- For the next eight weeks, starting on the nearest Monday:
  - Monday: Case study or proof
  - Thursday: Useful tip

For each email:

- Stick to the AI Company Context Document 100%.
- Do not invent, assume, or add information.
- Preserve the author’s tone.
- Make the email feel like it was personally written by the salesperson.
- Do not make it sound like a marketing email.
- Reference the previous sales conversation naturally without inventing details.
- Communicate one main idea.
- Use plain English and short paragraphs.
- Change the introduction, ending, and sign-off throughout the series.
- End with a clear CTA and link to book another call.
- Treat all emails as one connected series.
- Make every email understandable if the prospect missed the previous emails.
- Follow the Global Copywriting Rules.
- If essential information is missing, ask for it instead of inventing it.

For each email, provide:

1. Email number
2. Send day
3. Purpose
4. Subject line
5. Preview text
6. Finished email

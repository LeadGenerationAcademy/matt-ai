### Framework & Criteria

1. **Trigger:** Someone books a call.
2. **Sender:** Sent from the company, automatically.
3. **Message Includes:**
  1. Confirms the call
  2. Link to the Loom
  3. Link to the One-Pager

**Use This Template**

Your call with [Company] is confirmed.

Before the call, please review the short loom video and one-pager linked below. It contains everything you need to know before the call: We look forward to speaking with you.

Loom: [Loom Link]

One-Pager: [One-Pager Link]

We look forward to speaking with you.

### Step-by-Step Instructions

1. **Make A Copy Of The [Call Book Confirmation SMS Template](https://docs.google.com/document/d/1vUKmnyABEi6_vFubefRIL7BJ56gbxd_mYA4V8F-hfLo/edit?tab=t.8rckzhcfukqe), Or Skip If You Already Made One For A Previous Step.** Use this copy to fill in your version instead of starting from a blank message. [in this skill: assets/templates/welcome-flow-template/]
2. **Add The Company Name To The Template.** This is the only name in the message. The message is fully automated, so nothing needs to be personalized after setup.
3. **Add A Loom Link To The Template.** You will create this Loom in the Funnel Videos course, which is the next course after this one.
4. **Add The One-Pager Link To The Template.** Reuse the same One-Pager you already built for Step #14. Don't create a new one just for this message.
5. **Add The Template To Your SMS Tool.** Load the finished message into whatever platform will actually send it.
6. **Connect The Template To The Call-Booked Automation.** This ties the message to Zapier (or your equivalent tool) so it sends the moment a call is booked.
7. **Set The Message To Send Automatically.** This is an official confirmation from the company, so it gets sent automatically instead of manually by a person.
8. **Book A Test Call And Confirm It Sends Correctly.** This message is fully automated, and a broken link means the prospect walks into the call with zero preparation. Confirm:
  1. The message sends automatically the moment the call is booked
  2. The company name populates correctly
  3. The One-Pager link works
  4. Test the Loom link once you've added it in the Funnel Videos course.

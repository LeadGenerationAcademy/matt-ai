### Step-by-Step Instructions

1. **Make A Copy Of The [Global Writing Rules Template](https://docs.google.com/document/d/1l59ogG17NgNFGXN1jlz2aqwlxsH2s-dbjhk2Fuox1Ow/edit?tab=t.0), Or Skip If You Already Made One For A Previous Step.** This is the same shared document used for every template in this module, so if you already made a copy in a previous step, just navigate to the Global Writing Rules tab inside it instead of making a new copy. [in this skill: assets/templates/welcome-flow-template/]
2. **Paste The Global Writing Rules Into Every Existing AI Project.** These rules apply to every type of copy you write, ad copy, landing page copy, and email flow copy alike, so this includes every project you already have set up, not just the newest one.
3. **Paste The Global Writing Rules Into Every New AI Project Going Forward.** Every future project should start with the same base rules so your voice and standards stay consistent as your business grows.
4. **Edit The Global Writing Rules As You Use It, To Have It More Related To You.** If you notice AI drifting from your tone or repeating the same mistake across projects, add a new rule to the master document rather than fixing it inside one project only, so the fix carries forward everywhere you paste it.

- Did you paste the Global Writing Rules into every new AI project going forward?

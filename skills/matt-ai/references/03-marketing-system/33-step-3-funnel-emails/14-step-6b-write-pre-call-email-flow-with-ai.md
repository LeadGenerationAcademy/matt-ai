### AI Prompt:

Using only the AI Company Context Document below, write the complete 18-email Pre-Call Flow.

Create one email for each of the 18 most important FAQs and objections contained in the document.

Arrange them by importance because prospects who book closer to the call may only receive the first few emails.

For each email:

- Stick to the AI Company Context Document 100%.
- Do not invent, assume, or add information.
- Preserve the author’s tone.
- Write between 300 and 1,000 words.
- Answer one FAQ or objection.
- Use theory or overview, an example, and action steps.
- Include concrete proof whenever it is available.
- Reference the upcoming call differently.
- Change the introduction and sign-off without becoming casual or unprofessional.
- Do not use the same introduction or sign-off in consecutive emails.
- Create a subject line based on the FAQ using seven words or fewer.
- Create preview text that builds curiosity using five words or fewer.
- Treat all 18 emails as one connected series.
- Make every email understandable if the reader missed the previous emails.
- End every email with the one-pager and Loom links contained in the document.
- Follow the Global Copywriting Rules.
- If essential information is missing, ask for it instead of inventing it.

For each email, provide:

1. Email number
2. FAQ or objection
3. Subject line
4. Preview text
5. Finished email

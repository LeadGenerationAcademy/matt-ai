##### Step #1: Connect Your Tools

Connect [Zapier](https://zapier.com/app/assets/connections) to:

- [Your CRM](https://drive.google.com/file/d/1aaTZ1ZB_pzjdHj7feq-TQC8l7HdoWzxW/view?usp=sharing)

- [Your call booking tool](https://drive.google.com/file/d/1tK3z0oq0cMvtqyoxeS_2p3Ab2OpxFVCf/view?usp=sharing)
- [Your SMS tool](https://drive.google.com/file/d/1VexT7CqAvY-3aPunfsdoxCpUBumDeB5F/view?usp=sharing)

##### Step #2: Lead Magnet Automation

- [Video Tutorial](https://drive.google.com/file/d/1BUkmHS19EUFfmNfwfJNDDV2IHbH34Etu/view?usp=sharing)

When someone requests the lead magnet: ([Zapier](https://zapier.com/))

1. Send the Lead Magnet Delivery Email. ([Kit](https://app.kit.com/dashboard))
2. Wait five minutes. ([Kit](https://app.kit.com/dashboard))
3. If they have not booked a call, add them to the Welcome Flow. ([Kit](https://app.kit.com/dashboard))

##### Step #3: Application Automation

- [Video Tutorial](https://drive.google.com/file/d/1MTDHGgnTgUC7tpiZDMMnLVyCJUxbCX2s/view?usp=sharing) (use the same calendly zapier workflow Step 2)

When someone completes an application: ([Zapier](https://zapier.com/))

1. Send the Application Confirmation SMS. ([Roezan](https://app.roezan.com/admin/dashboard))
2. Wait five minutes. ([Roezan](https://app.roezan.com/admin/dashboard)) ([Kit](https://app.kit.com/dashboard))
3. If they have not booked, send the Appointment-Setting Message. ([Roezan](https://app.roezan.com/admin/dashboard))
4. Add them to the Welcome Flow. ([Kit](https://app.kit.com/dashboard))

##### Step #4: Call-Booked Automation

- [Video Tutorial](https://drive.google.com/file/d/18dO5noOQqk1J8VJ0ZHmALy7XIjIjDxkH/view?usp=sharing) (use the same calendly zapier workflow as step 2 & 3)

When someone books a call: ([Zapier](https://zapier.com/))

1. Remove them from the other flows. ([Kit](https://app.kit.com/dashboard))
2. Add them to the Pre-Call Flow. ([Kit](https://app.kit.com/dashboard))
3. Send the Call-Booked Confirmation SMS. ([Roezan](https://app.roezan.com/admin/dashboard))
4. Send the Call-Booked Appointment-Setting Message. ([Roezan](https://app.roezan.com/admin/dashboard))
5. Create a task to send the Selfie Video. ([Zapier](https://zapier.com/))

##### Step #5: No-Show Automation

- [Video Tutorial](https://drive.google.com/file/d/194hTKiKs6jmfb6cpEQ6hZuDrSH3Wn68w/view?usp=sharing)

When someone is marked as a no-show: ([Zapier](https://zapier.com/))

1. Remove them from the Pre-Call Flow. ([Kit](https://app.kit.com/dashboard))
2. Add them to the No-Show Flow. ([Kit](https://app.kit.com/dashboard))

##### Step #6: Follow-Up Automation

- [Video Tutorial](https://drive.google.com/file/d/1VKudVKjJdEntWI_qLLwIJbp0VnSLaG3X/view?usp=sharing) (use the same zapier workflow as step 5)

When a call ends without a sale: ([Zapier](https://zapier.com/))

1. Remove them from the Pre-Call Flow. ([Kit](https://app.kit.com/dashboard))
2. Add them to the Follow-Up Flow. ([Kit](https://app.kit.com/dashboard))
3. Start the 90-day timer. ([Kit](https://app.kit.com/dashboard))
4. Start the 180-day timer. ([Kit](https://app.kit.com/dashboard))
5. Start the 365-day timer. ([Kit](https://app.kit.com/dashboard))

##### Step #7: Winback Automations

- [Video Tutorial](https://drive.google.com/file/d/1KLi8P4279qz7JamYfnK94WytCL1AC5Ag/view?usp=sharing)

When each timer ends: ([Kit](https://app.kit.com/dashboard))

1. Check whether they became a customer. ([Kit](https://app.kit.com/dashboard))
2. If they did not, add them to the correct Winback Flow. ([Kit](https://app.kit.com/dashboard))

##### Step #8: Customer Removal Automation

- [Video Tutorial](https://drive.google.com/file/d/1jxCNjoVWjh0Ic4fUHFDik8uSYhToH_Yc/view?usp=sharing)

When someone becomes a customer: ([Zapier](https://zapier.com/))

1. Remove them from every sales flow. ([Kit](https://app.kit.com/dashboard))
2. Remove them from every Winback Flow. ([Kit](https://app.kit.com/dashboard))

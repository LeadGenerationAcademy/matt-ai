Your CRM needs to become the central record of where every person currently stands in your funnel. Some platforms connect to your CRM natively, so use that connection first if it exists. If a native integration isn't available, connect the two through an automation platform like Zapier instead.

### Step-by-Step Instructions

1. **List every platform that needs to connect to your CRM.** This includes your opt-in form, application form, calendar, email platform, and SMS platform, anything generating an event you'll need Flows or reporting to react to later.
2. **Check each platform for a native CRM integration, and turn it on wherever one exists.** A native integration is more reliable and faster to set up than routing the same connection through an automation platform. Use it whenever it's available.
3. **Sign up for an automation platform like [Zapier](https://zapier.com) if you don't already have one.** You only need this for the platforms that don't offer a native connection.
4. **Connect any remaining platform to your CRM through the automation platform.** This covers whatever's left after native integrations are turned on.
5. **Test each connection by triggering a real event on that platform.** Submit a form, book a test call, or send a test message, whatever actually fires that specific connection.
6. **Confirm the event shows up correctly on the contact's CRM record, and that the contact wasn't duplicated.** This is what proves the connection is actually working. Duplicate records split a single person's history across two contacts, which quietly breaks your Flow triggers and Metrics later.

### Completion Audit

- Did you list every platform that needs to connect to your CRM?
- Did you check each platform for a native CRM integration and turn it on wherever one exists?
- Did you sign up for an automation platform like Zapier if you didn't already have one?
- Did you connect any remaining platform to your CRM through the automation platform?
- Did you test each connection by triggering a real event on that platform?
- Did you confirm the event shows up correctly on the contact's CRM record, and that the contact wasn't duplicated?

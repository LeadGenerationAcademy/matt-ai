### Step-by-Step Instructions

1. **Open the Leaderboard tab in your Accountability Work Form spreadsheet.** It sits alongside everyone's Work Form tabs. The headers and formulas are already in it.
2. **Replace Name 1, Name 2 and Name 3 in column A with each person's first name.** One name per row, starting at A2. Delete any placeholder you do not need.
3. **Check every person's tab name matches their name in column A.** The tab has to read exactly "[Their Name]'s Work Form", apostrophe included. "Matts Work Form" will not match "Matt".
4. **Confirm every person's row fills in automatically.** Never type anything into columns B to G yourself. Adding someone later means typing their name in the next empty cell in column A, nothing more.

### Completion Audit

- Did you open the Leaderboard tab in your Accountability Work Form spreadsheet?
- Did you replace Name 1, Name 2 and Name 3 in column A with each person's first name?

- Does every person's row fill in automatically?

### Step-by-Step Instructions

1. **Create a new ChatGPT Project called "Financial Tracking".** Use the equivalent inside whichever AI you use if you are not on ChatGPT.
2. **Upload the spreadsheet into the project.** This gives it the exact format every transaction has to come back in.
3. **Keep all future transaction formatting inside this project.** Once the entities, categories, accounts and currencies are configured, the project already has that context the next time you update it, so you are not explaining your setup every month.

### Completion Audit

- Did you create a new ChatGPT Project called Financial Tracking?
- Did you upload the spreadsheet into the project?
- Are you keeping all future transaction formatting inside this project?

### Template

- Set bedtime for nine hours before your wake-up time.

- Clean your workspace.
- Prepare everything required for the morning routine.
- Set yourself up for a great sleep.
- Review your day.
- Write down three improvements for tomorrow.
- Go to bed without your phone in the room.

### Step-by-Step Instructions

1. **Copy the checklist above.** It is already written out for you. There is nothing to rewrite.
2. **Open Apple Notes and create a note called "Night Checklist."** Or the same notes app you used to create the other documents.
3. **Paste the checklist into the note.** You can print it instead if you would rather have it on paper.
4. **Leave the actual routine for later.** We will build the actual routine later. For now, create the checklist.

### Step-by-Step Instructions

1. **Create a note called "Self Mastery List."** It goes inside your Lists folder. This is where you will record everything you need to gain greater control over.
2. **Add anything obvious.** You will already know some of the things you have no control over. Write those down.
3. **Otherwise, leave it blank for now.** This is one of the four lists we keep returning to as we build the Daily System, so it fills up as you go.

### Completion Audit

- Did you create a note called "Self Mastery List"?
- Did you add anything obvious?
- Did you leave it blank if nothing came to mind?

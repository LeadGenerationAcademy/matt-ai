The Theory explains that you need a set of apps, extensions and spreadsheets to run everything in this System. Almost all of it is free or a small subscription fee, and the ROI on it is absolutely insane.

In this course you will download everything that you need to run the System.

Downloading is all you are doing here. Creating, configuring and setting it all up happens in the next course.

Do not sit there researching which calorie app or stretching app is better. They are for the most part all the same. Just download the ones I have listed, or the ones you already have, and move on.

### Step-by-Step Instructions

1. **Install [Tab Limiter](https://chromewebstore.google.com/detail/tab-limit/djdcpjfmniidpdaalloiipgjphgikejl) in Chrome.** It is a Chrome extension. It installs straight from the Chrome Web Store in a couple of clicks.
2. **Pin the extension to the top of your browser.** Right click the extension icon and press Pin. You want it sitting there in view instead of buried in the extensions menu.
3. **Set the maximum number of tabs you are allowed to have open.** This is the number it holds you to. Nothing destroys a work session quite like having 40 tabs everywhere.

### Completion Audit

- Did you install Tab Limiter in Chrome?
- Did you pin the extension to the top of your browser?
- Did you set the maximum number of tabs you are allowed to have open?

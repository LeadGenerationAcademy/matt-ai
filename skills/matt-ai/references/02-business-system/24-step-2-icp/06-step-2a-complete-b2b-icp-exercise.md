### Step-by-Step Instructions

1. **Open the ICP Spreadsheet you made a copy of in Step #1.** This is the working document you'll use to categorize every customer you exported.
2. **Go to the "ICP B2B Exercise" tab.** This tab is already built with all six B2B fields ready to fill in.
3. **Paste your exported customer names into the Name column if you haven't already.** Each row should represent one customer.
4. **Assign each customer an Age range using the dropdown.** Options run from 18-24 up through 55+.
5. **Assign each customer a Gender using the dropdown.** Options are Male or Female, this should be obvious for most customers.
6. **Assign each customer an Annual Company Revenue range using the dropdown.** Options run from $0 up through $10 million+, adjust these ranges to fit your business if they don't match your typical customer.
7. **Assign each customer a Country using the dropdown.** Guess if you don't know for certain, but you usually will.
8. **Assign each customer a Region, State, City, or ZIP when relevant.** This only matters if your business targets a specific area within a country.
9. **Assign each customer a Job Title using the dropdown.** Options run from Founder and CEO down through Director/VP/Head of X, Manager or Team Lead, and Employee.
10. **Assign each customer an Employee Count range using the dropdown.** Options run from 1 up through 250+, adjust these ranges to fit your business if they don't match your typical customer.
11. **Estimate any answer you don't know exactly.** In most cases the answer will be obvious even if you can't confirm it for certain, so don't leave a cell blank.

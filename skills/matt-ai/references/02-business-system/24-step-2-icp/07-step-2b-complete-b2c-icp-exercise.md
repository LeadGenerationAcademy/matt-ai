### Step-by-Step Instructions

1. **Open the ICP Spreadsheet you made a copy of in Step #1.** This is the working document you'll use to categorize every customer you exported.
2. **Go to the "ICP B2C Exercise" tab.** This tab is already built with all nine B2C fields ready to fill in.
3. **Paste your exported customer names into the Name column if you haven't already.** Each row should represent one customer.
4. **Assign each customer an Age range using the dropdown.** Options run from 18-24 up through 65+.
5. **Assign each customer a Gender using the dropdown.** Options are Male or Female, this should be obvious for most customers.
6. **Assign each customer a Country using the dropdown.** Guess if you don't know for certain, but you usually will.
7. **Assign each customer a Region, State, City, or ZIP when relevant.** This only matters if your business targets a specific area within a country.
8. **Assign each customer a Marital Status using the dropdown.** Options run from Single through In a Relationship, Married, Divorced, and Widowed.
9. **Assign each customer a Children category using the dropdown.** Options run from No Children through Expecting, 1 Child, 2 Children, and 3+ Children.
10. **Assign each customer a Homeowner Status using the dropdown.** Options run from Renter through Homeowner With/Without a Mortgage, Living With Family, and Other.
11. **Assign each customer an Annual Household Income range using the dropdown.** Options run from Under $25,000 up through $500,000+, adjust these ranges to fit your business if they don't match your typical customer.
12. **Assign each customer a Household Net Worth range using the dropdown.** Options run from Negative up through $5 million+, adjust these ranges to fit your business if they don't match your typical customer.
13. **Assign each customer an Employment category using the dropdown.** Options run from Business Owner and Executive down through Manager, Employee, Self-Employed, Student, Retired, and Unemployed.
14. **Estimate any answer you don't know.** In most cases the answer will be obvious even if you can't confirm it for certain, so don't leave a cell blank.

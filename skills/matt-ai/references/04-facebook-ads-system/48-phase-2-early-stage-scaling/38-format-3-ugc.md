### Step-by-Step Instructions

1. **Use the casual, phone-filmed style to present the offer.** This is meant to look organic, and there can be a few different subformats within it. A direct explanation, an FAQ response or a comment-response video can all use this style.
2. **Give the presenter the approved script and a reference for the delivery and framing.** The person should sound like they are speaking naturally, but we still need the offer and important details to come through.
3. **Have them read the script out loud before recording.** This is so awkward wording can be fixed.
4. **Apply the editing rules from [Step #12B: Editing Framework](https://www.skool.com/leadgenerationacademy/classroom/031026d9?md=0a382512e8c74c4f9122efb415327707).** Identify the ICP immediately, add readable captions and use relevant proof.
5. **Create more variations with different presenters and framing once you have a good version.** This gives us more versions around the same message.

### Completion Audit

- Did you use the casual, phone-filmed style to present the offer?
- Did you give the presenter the approved script and a reference for the delivery and framing?
- Did you have them read the script out loud before recording?
- Did you apply the editing rules from Step #12B: Editing Framework?
- Are you creating more variations with different presenters and framing once you have a good version?

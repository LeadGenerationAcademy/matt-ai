### Step-by-Step Instructions

1. **Use ABO for the testing campaign you created in [Step #13A: Scaling vs. Testing Campaigns](https://www.skool.com/leadgenerationacademy/classroom/031026d9?md=b22cce5d2175471daafbf0c0a7cb3d19).** ABO lets us set the budget for each ad set.
2. **Create one ad set per group of a particular variable.** Group by something like format, concept or avatar. If we group by format, for example, the static images go together and the talking-head videos go together. That gives us a way to compare the groups and control how much each receives. Keep as few ad sets as possible without making the groups useless, since every additional ad set needs its own budget and conversion data.
3. **Aim for around 50 optimization events per ad set over seven days.** This is the usual target for the learning phase. Those are the events we optimize for, which could be leads or booked calls.
4. **Put several ads into each ad set.** Some people will tell you to put one ad in each ad set so every ad gets its own budget. I see their point, but I do not recommend that at this stage. If we only have $500 per day for testing, we either test very few ads with meaningful spend or put so many into separate ad sets that each gets very little. Remember the power law from Step #12A: Ad Creative Production System. Most ads will not work. We need enough attempts to find the few that make the effort worth it.
5. **Let Facebook decide how to spend each ad set's budget.** Grouping lets Facebook put more of the budget toward the ads it chooses to deliver. Some will get most of the spend. Others will barely spend. We have to accept that this does not give every individual ad a complete test.

### Completion Audit

- Did you use ABO for the testing campaign you created in Step #13A: Scaling vs. Testing Campaigns?
- Did you create one ad set per group of a particular variable?
- Are you aiming for around 50 optimization events per ad set over seven days?
- Did you put several ads into each ad set?
- Are you letting Facebook decide how to spend each ad set's budget?

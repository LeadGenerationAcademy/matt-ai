# Dream 100 Copy Template

You will be creating the opening message to send to your Dream 100 list.

You are not going to be sending them your One-Pager in this message, you are just asking if they will be interested.

# **Use This Template**

Hey \[First Name\], we help X niche achieve Y result.

We have worked with \[X, Y, Z\].

I can send over a one pager if you’re interested.

**Example:**

"Hey \[First Name\], we help \[Niche\] achieve \[Result\]

We have worked with \[X, Y, Z\].

I can send over a one pager if you're interested."

# **Write Your Dream 100 Copy**

Hey John, we help agency owners generate more leads.

We have worked with Northpoint Digital, Southpoint Media, and Eastpoint Agency.

I can send over a one pager if you're interested.
